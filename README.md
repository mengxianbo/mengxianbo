### ⚡ OpenRung for OpenWrt

**OpenWrt / KWRT x86_64 · CLI + LuCI · GitHub Actions**

面向 OpenWrt 的 OpenRung 管理方案，提供中文 LuCI 管理页面、本地代理端口配置、procd 后台服务与开机启动支持。

- 本地代理默认监听：`127.0.0.1:44025`（可在 LuCI 页面修改）
- procd 服务管理与异常自动重启
- 显示实际监听状态，辅助排查服务运行问题
- GitHub Actions 自动构建 IPK 安装包
